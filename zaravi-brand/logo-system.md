# ZARAVI LOGO SYSTEM
*Based on Territory B: Dark Romantic / Editorial / Couture*

---

## LOGO ARCHITECTURE OVERVIEW

The ZARAVI logo system is built on precision, drama, and editorial authority. Every variation serves a specific function — no redundant marks.

### Design Principles

1. **Typography-led** — The wordmark is the primary brand signifier
2. **Editorial serif** — High-contrast, fashion-masthead quality
3. **Scale-sensitive** — Each variation designed for its specific size
4. **Monochrome-first** — Works in single color before metallics
5. **Embedded butterfly** — Butterfly appears as structural element, not decoration

---

## PRIMARY WORDMARK

### ZARAVI (Primary)

**Construction:**
- Typeface: Customized Playfair Display / Didot-style editorial serif
- Weight: Medium (500) — substantial without being heavy
- Tracking: +200 (2em) — dramatic, breathable, editorial
- Case: ALL CAPS
- Ligature treatment: Custom "Z-A" and "V-I" connections

**Custom Typographic Details:**
- **Z**: Extended horizontal arms, sharp terminals
- **A**: Crossbar lowered to 1/3 height, pointed apex
- **R**: Leg extends slightly below baseline
- **V**: Sharp vertex, arms at 45°
- **I**: Minimal serif, vertical precision

**Proportions:**
- Cap height: 1 unit
- Letter width: 0.65 units (average)
- Inter-letter spacing: 0.2 units
- Total wordmark width: 6.9 units

**Clear Space:**
- Minimum: 0.5x cap height on all sides
- Measured from "Z" and "I" extremities

### ZARAVI JEWELRY (Secondary Wordmark)

**Construction:**
- "ZARAVI" as primary wordmark
- "JEWELRY" in small caps, tracking +300 (3em)
- "JEWELRY" font size: 0.3x primary cap height
- Vertical alignment: "JEWELRY" baseline aligns with primary baseline
- Horizontal: "JEWELRY" centered under "ZARAVI"

**Spacing:**
- Gap between lines: 0.15x cap height
- "JEWELRY" extends 0.5 units beyond "Z" and "I" on each side

## SYMBOL SYSTEM

### Z MONOGRAM

**Construction:**
- Derived from "Z" in primary wordmark
- Extended horizontal arms form symmetrical wings
- Center vertical stroke creates body
- Proportions: 1:1 square bounding box

**Variations:**
1. **Outline** — Hairline weight (0.05x), for embossing, engraving
2. **Solid** — Filled, for favicon, small digital
3. **Gold foil** — For premium applications
4. **Butterfly-integrated** — Wings suggest butterfly symmetry

**Technical Specs:**
- Minimum size: 6mm (print), 16px (digital)
- Stroke weight scales proportionally
- No smaller than 4mm for outline version

### BUTTERFLY SYMBOL (Primary Emblem)

**Design Concept:**
Not a literal butterfly. An abstract, geometric interpretation derived from butterfly wing symmetry and structural principles.

**Construction:**
- Two symmetrical wing forms
- Each wing: asymmetrical teardrop with geometric facets
- Central negative space forms subtle body
- Total form fits in 1:1 square
- Line weight: 0.08x bounding box

**Geometric Logic:**
- Wing angle: 30° from vertical
- Outer curve: Bezier with 3 control points
- Inner facet: Angular, architectural
- Symmetry: Perfect horizontal mirroring

**Level 1 — Primary Emblem:**
- Solid filled version (dark espresso / gold foil)
- Used on: packaging seals, jewelry tags, certificates
- Minimum: 8mm diameter

**Level 1b — Outline Emblem:**
- Hairline weight (0.04x)
- Used on: wax seals, embossing, blind deboss
- Minimum: 10mm diameter

### BUTTERFLY SYMBOL (Secondary — Fragmented)

**Design Concept:**
Cropped, partial butterfly forms that suggest the whole without showing it.

**Variations:**
1. **Single wing** — Right wing only, facing right (forward motion)
2. **Wing pair, open** — Wings separated by 0.5x gap (emergence)
3. **Wing fragment** — Lower 1/3 of wing (pattern/texture use)
4. **Symmetry axis** — Central line with wing suggestions

**Usage:**
- Pattern generation
- Micro-details
- Digital loading states
- Packaging interior details

## COMBINED LOCKUPS

### Horizontal Lockup (Primary)

```
[BUTTERFLY EMBLEM]  ZARAVI  JEWELRY
```

**Construction:**
- Butterfly emblem: 1.2x cap height
- Gap: 0.4x cap height
- "JEWELRY" small caps, centered under "ZARAVI"
- Total width: ~10x cap height

**Color Options:**
1. Emblem: gold foil / Wordmark: dark espresso
2. All dark espresso (monochrome)
3. All gold foil (premium)

### Stacked Lockup

```
   [BUTTERFLY EMBLEM]
      ZARAVI
    JEWELRY
```

**Construction:**
- Emblem: 1.5x cap height
- Gap below emblem: 0.3x cap height
- "ZARAVI" at primary tracking
- "JEWELRY" small caps, +300 tracking
- Total height: ~4x cap height

**Usage:** Shopping bags, gift boxes, store signage

### Icon-Only Mark

**Usage:** Favicon, app icon, social avatar, jewelry engraving

**Versions:**
1. **Z Monogram** — 16px, 32px, 48px, 128px
2. **Butterfly Emblem (solid)** — 16px+
3. **Butterfly Emblem (outline)** — 24px+ (detail loss at small sizes)

**Favicon Specifics:**
- 16px: Z monogram solid only
- 32px: Butterfly emblem simplified
- 48px+: Butterfly emblem full detail

### Jewelry Engraving Mark

**Requirement:** Must work at 1.5mm - 3mm

**Design:**
- Z monogram outline only
- Stroke: 0.15mm minimum
- No fill
- Simplified geometry (fewer Bezier points)
- Tested at 1mm, 2mm, 3mm

## CLEAR SPACE & MISUSE

### Clear Space Rule
Minimum clear space = 0.5x cap height of "ZARAVI" wordmark
Measured from furthest extremities of the mark

### Minimum Sizes
- Primary wordmark: 20mm width (print) / 120px (digital)
- Butterfly emblem: 8mm diameter (print) / 24px (digital)
- Z monogram: 4mm (print) / 16px (digital)
- Engraving mark: 1.5mm (metal stamping)

### Misuse Prohibitions

**DO NOT:**
- Recreate the wordmark with different fonts
- Change tracking/kerning
- Use lowercase or sentence case
- Place on busy backgrounds without clear space
- Add drop shadows, glows, or effects
- Rotate the logo
- Stretch or distort proportions
- Use butterfly emblem without wordmark (except approved icon-only uses)
- Combine with other logos without partnership agreement
- Place gold foil version on colored backgrounds (only on dark espresso or black)
- Use outline emblem at sizes below 10mm
- Add taglines directly to lockups (use separate typography)

## APPLICATION SPECIFICATIONS

### Print Production

**Letterpress:**
- Wordmark: Deep impression, dark espresso ink
- Butterfly: Blind impression (no ink)

**Foil Stamping:**
- Gold foil: 0.15mm thickness
- Temperature: 110-130°C
- Pressure: Medium-heavy
- Paper: Uncoated cotton stock

**Embossing:**
- Blind emboss: 0.3mm depth
- Registered emboss: With gold foil
- Butterfly outline only

**Offset/Litho:**
- Dark espresso: Pantone 4625 C
- Gold: Pantone 871 C (metallic)
- No CMYK builds for brand colors

### Digital Production

**Web Fonts:**
- Playfair Display (via Google Fonts) — display
- Libre Baskerville (via Google Fonts) — body
- Inter (via Google Fonts) — UI/labels

**SVG Specifications:**
- All logos delivered as optimized SVG
- ViewBox: 0 0 690 100 (wordmark)
- No embedded fonts (outlines only)
- IDs for CSS targeting: #zaravi-wordmark, #butterfly-emblem

**Responsive Logo:**
```css
/* Breakpoints */
@media (max-width: 480px) { /* Horizontal Compact */ }
@media (max-width: 320px) { /* Z Monogram only */ }
```

### Jewelry Application

**Engraving (Metal):**
- Laser engraving: 0.1mm spot size
- Depth: 0.05mm
- Mark: Z monogram only
- Placement: Interior band (rings), clasp (necklaces), post (earrings)

**Stamping (Metal):**
- Die: Hardened steel
- Pressure: Hydraulic
- Mark: Z monogram outline
- Size: 2mm - 4mm depending on piece

**Hang Tags:**
- Material: 400gsm uncoated cotton
- Front: Stacked lockup, gold foil
- Back: Product info, QR code
- String: Satin ribbon, burnt sienna

## BRAND SIGNATURE BEHAVIOR

The ZARAVI logo system has a "breathing" quality:

**Animation (Digital):**
- Wordmark: Letters emerge sequentially (800ms total, 100ms stagger)
- Butterfly: Wings unfold from center line (800ms, organic ease)
- Stagger: Wordmark completes, then butterfly (200ms delay)

**Physical (Packaging):**
- Blind emboss inside box lid — discovered on opening
- Wax seal on gift box — broken to open
- Ribbon pull reveals logo on tag
