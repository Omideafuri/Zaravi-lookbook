## STATIONERY SYSTEM

### Design Philosophy

Every piece of stationery is a **brand artifact** — not administrative necessity. The stationery system should feel like a curated collection of objects, each with distinct purpose and material integrity.

**Principles:**
- Materiality over decoration
- Blind techniques over ink (where possible)
- Consistency of system, not uniformity of appearance
- Each piece serves its specific ritual

1. Greeted by name (if known) / warm welcome

7. Move to alcove

11. Return to Gallery or Wrap Station

13. Certificate, care card, polishing cloth included

**Departure:**
14. Bag presented with both hands
15. "Thank you for choosing ZARAVI"
16. Follow-up: Handwritten note (3 days), email (1 week)

```
Row 1: Campaign Hero  |  Editorial  |  Campaign Detail
Row 2: Product Hero   |  Journal     |  Product Detail
Row 3: Process        |  Community   |  Campaign Hero
```

## MOTION SYSTEM

### Motion Philosophy

**Movement as Metamorphosis**

Every animation tells the same story: *Something emerges. Something unfolds. Something becomes.*

---

### MOTION PRINCIPLES (Recap from Digital System)

1. **Unfolding** — Center outward, never slide in
2. **Symmetry** — Bilateral, balanced
3. **Organic Easing** — cubic-bezier(0.25, 0.46, 0.45, 0.94)
4. **Breath** — Hover states breathe, don't snap
5. **Cinematic Duration** — Longer than expected (500-800ms)
6. **No Bounce** — No elasticity, no playfulness

---

### LOGO ANIMATION (Master)

**Duration:** 800ms
**Easing:** Organic (cubic-bezier(0.25, 0.46, 0.45, 0.94))

**Sequence:**
```
0ms      : Blank
100ms    : Symmetry axis draws downward (200ms)
200ms    : Left wing upper curve begins
250ms    : Right wing upper curve begins (mirrored)
400ms    : Both wings reach apex simultaneously
550ms    : Lower curves complete
700ms    : Facet notches "click" (scale 0→1, 50ms each)
800ms    : Complete — subtle gold glow pulse (200ms decay)
```

**Variants:**
- **Full:** Wordmark + Butterfly (homepage, app launch)
- **Symbol Only:** Butterfly only (favicon, loading)
- **Wordmark Only:** Letters stagger (100ms each) — 700ms total
- **Reverse:** For page exit (wings fold, axis retracts)

---

### UI MOTION LIBRARY

#### Page Transitions

**Standard (Internal Links):**
- Exit: Content folds along vertical center (300ms, exit ease)
- Pause: 100ms (chrysalis)
- Enter: New content unfolds from center (300ms, enter ease)
- Total: 700ms

**Modal / Overlay:**
- Backdrop: Fade in (200ms)
- Panel: Scale 0.95→1 + fade (300ms, organic)
- Close: Reverse (200ms)

**Drawer (Cart, Menu):**
- Slide from right (400ms, organic)
- Backdrop: Fade (200ms)
- Content: Staggered reveal (50ms stagger)

#### Image Reveals

**Wing Mask Reveal (Hero Images):**
- SVG mask: Level 1 butterfly shape
- Mask expands from center (radial)
- Duration: 600ms, organic ease
- Image: Slight scale (1.05→1.0) during reveal

**Scroll Reveal (Editorial):**
- Trigger: 20% in viewport
- Action: Fade + translate Y (30px→0)
- Duration: 800ms, organic ease
- Stagger: 100ms per element in group

#### Micro-Interactions

**Button Hover:**
- Background color shift only (espresso → burnt sienna)
- Duration: 150ms, enter ease
- No transform, no shadow change

**Button Active:**
- Background: Deep olive
- Duration: 50ms (instant feel)

**Link Hover (Editorial):**
- Underline draws from center (width 0→100%, left 50%→0)
- Duration: 300ms, organic ease
- Color shift: Dark espresso → burnt sienna

**Card Hover (Product):**
- Scale: 1.0 → 1.015 (barely perceptible)
- Shadow: Subtle → soft
- Alt image: Wing-mask reveal (500ms)
- Duration: 300ms, organic ease

**Form Focus:**
- Border: Stone → burnt sienna
- Duration: 100ms
- Label: Translates up, scales 0.85x (if floating label)

**Loading States:**

| Loader | Use | Spec |
|--------|-----|------|
| Emergence | Page, heavy loads | 12-frame butterfly build, 720ms loop |
| Wing Flutter | Checkout, API | Open wings ±3° rotation, 1.2s period |
| Facet Pulse | Button submit | Single diamond opacity 30%↔100%, 800ms |
| Skeleton | Content loading | Dark espresso blocks, shimmer (gold) |

#### Scroll Behaviors

**Parallax (Subtle):**
- Hero image: 0.3x scroll speed (max 100px translate)
- Campaign sections: 0.15x
- Never: Text, UI elements

**Progress Indicator:**
- Top bar: Gold foil line
- Width: Scroll progress (0→100%)
- Height: 2px
- Organic ease (follows scroll naturally)

**Section Snap (Optional):**
- Campaign pages only
- Snap points at section boundaries
- Organic ease, 600ms
- Respect prefers-reduced-motion

### MOTION TOKENS (CSS/Design System)

```css
:root {
  /* Durations */
  --motion-instant: 50ms;
  --motion-fast: 150ms;
  --motion-normal: 300ms;
  --motion-slow: 500ms;
  --motion-cinematic: 800ms;
  --motion-epic: 1200ms;

  /* Easings */
  --ease-organic: cubic-bezier(0.25, 0.46, 0.45, 0.94);
  --ease-enter: cubic-bezier(0, 0, 0.2, 1);
  --ease-exit: cubic-bezier(0.4, 0, 1, 1);
  --ease-sharp: cubic-bezier(0.4, 0, 0.6, 1);

  /* Delays */
  --stagger-micro: 50ms;
  --stagger-small: 100ms;
  --stagger-medium: 150ms;
  --stagger-large: 200ms;

  /* Reduced Motion */
  @media (prefers-reduced-motion: reduce) {
    --motion-instant: 0ms;
    --motion-fast: 0ms;
    --motion-normal: 0ms;
    --motion-slow: 0ms;
    --motion-cinematic: 0ms;
    --motion-epic: 0ms;
  }
}
```
